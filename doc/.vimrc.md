# Vim説明書

以下のVimスクリプトは、`~/.config/vim/vim.vim`設定ファイルが存在して読み込み可能であることを確認した後に、それをセッションに読み込む。

```Vim
if filereadable(expand("~/.config/vim/vim.vim"))
    source ~/.config/vim/vim.vim
endif
```

# Vim Document

The Vim script below loads the configuration file `~/.config/vim/vim.vim` into the session after checking if it exists and is readable.

```Vim
if filereadable(expand("~/.config/vim/vim.vim"))
    source ~/.config/vim/vim.vim
endif
```
