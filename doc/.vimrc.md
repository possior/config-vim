## 設定ファイルを参照する

以下のVimscriptスクリプトは、`~/.config/vim/vim`が存在して読み込み可能であることを確認した後に、それをセッションに読み込む。

```Vimscript
if filereadable(expand("~/.config/vim/vim"))
    source ~/.config/vim/vim
endif
```

## Referencing Configuration File

The Vimscript script below loads the file `~/.config/vim/vim` into the session after checking if it exists and is readable.

```Vimscript
if filereadable(expand("~/.config/vim/vim"))
    source ~/.config/vim/vim
endif
```
