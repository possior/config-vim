## 導入

本リポジトリをGitで複製して`installer.sh`スクリプトを実行せよ。

```Bash
git clone https://github.com/possior/config-vim.git; ./config-vim/installer.sh; rm -rf config-vim
```

## Installation

Clone this repository using Git, and execute the `installer.sh` script.

```Bash
git clone https://github.com/possior/config-vim.git; ./config-vim/installer.sh; rm -rf config-vim
```
