## 設定ファイルの参照

以下のVimスクリプトは、`~/.config/vim/vim`が存在して読み込み可能であることを確認した後に、それをセッションに読み込む。

```Vim
if filereadable(expand("~/.config/vim/vim"))
    source ~/.config/vim/vim
endif
```

## Referencing Configuration File

The Vim script below loads the file `~/.config/vim/vim` into the session after checking if it exists and is readable.

```Vim
if filereadable(expand("~/.config/vim/vim"))
    source ~/.config/vim/vim
endif
```
